📥 ADB 本地代理 - 获取指南

ADB 本地代理是一个轻量级程序，用于在你的电脑上执行 ADB 命令。 它会启动一个本地服务，让网页能够控制你的 Android 设备。

📱

正式安装器（推荐）

安装包内含 ADB 运行所需文件，不需要安装 Node.js，也不需要手动配置 PATH。

1 下载并运行 adb-agent-setup.exe。
2 可选：下载 SHA256SUMS.txt 比对安装包哈希。
3 安装完成后回到 ADB 调试助手，启动助手并按页面提示输入本机 Token。

⚡

开发或现场排障备用

只在无法使用正式安装器时使用，必须固定到已发布的版本标签。

1 安装 Node.js 18+，并从 GitHub Release 下载同一版本的便携包。
2 解压后将 adb-agent.exe 与 ADB 文件保留在同一目录。
3 运行程序，复制控制台显示的 Token 并返回网页配对。
⚠️ 注意事项
  • 当前安装器尚未签名，Windows SmartScreen 提示需要由发布方配置代码签名证书后才能消除
  • 防火墙弹窗请选择"允许访问"（专用网络）
  • 程序只监听 127.0.0.1，安全可靠
  • 如果下载链接不存在，说明当前站点尚未发布对应版本，请联系发布方完成 GitHub Actions 部署
💡 使用流程
  1. 下载并运行本地代理程序
  2. 从本地代理窗口复制显示的 Token
  3. 返回 ADB 调试助手页面，粘贴 Token 进行配对
  4. 输入 Android 设备的 IP 地址，点击连接
  5. 开始执行 ADB 命令！
