📥 ADB 本地代理 - 获取指南

ADB 本地代理是一个轻量级程序，用于在你的电脑上执行 ADB 命令。 它会启动一个本地服务，让网页能够控制你的 Android 设备。

📱

前置要求：安装 ADB 工具

在使用本地代理之前，需要先安装 Android SDK Platform Tools

1 访问 Android SDK Platform Tools 官方下载页面
2 下载 Windows 版本的 Platform Tools
3 解压到任意目录（如 C:\platform-tools）
4 将目录添加到系统 PATH 环境变量，或将 adb.exe 复制到本地代理同目录
📥 下载 Platform Tools
⚡

方式一：一键下载并运行（推荐）

只需安装 Node.js，复制下方命令到 PowerShell 执行即可

1 确保已安装 Node.js 18+
2 按 Win + X，选择 Windows PowerShell
3 复制粘贴以下命令并回车：
cd $env:USERPROFILE; Invoke-WebRequest -Uri "https://github.com/ShiinaMayuri123/Online_Tools/archive/refs/heads/main.zip" -OutFile "toolbox.zip"; Expand-Archive -Path "toolbox.zip" -DestinationPath "." -Force; cd "Online_Tools-main\local-agent"; npm install; node index.js

💡 此命令会自动下载代理程序、安装依赖并启动。启动后请复制显示的 Token 回到网页配对。

⚠️ 如果仓库是私有的，需要先登录 GitHub 或使用 git clone 方式。

📥 先安装 Node.js
🔧

方式二：手动下载

从 GitHub 下载源码，手动运行

1 下载仓库 ZIP：点击下载，或 git clone 克隆仓库
2 解压后进入 local-agent 文件夹
3 双击 start.bat（自动安装依赖并启动）
4 如果 start.bat 不可用，打开终端手动执行：npm install 然后 npm start
🚀 访问 GitHub 仓库
⚠️ 注意事项
  • 首次运行可能被 Windows Defender 拦截，点击"更多信息" → "仍要运行"
  • 防火墙弹窗请选择"允许访问"（专用网络）
  • 程序只监听 127.0.0.1，安全可靠
  • 需要电脑上已安装 ADB 工具（下载地址）
💡 使用流程
  1. 下载并运行本地代理程序
  2. 程序会自动打开配对页面，复制显示的 Token
  3. 返回 ADB 调试助手页面，粘贴 Token 进行配对
  4. 输入 Android 设备的 IP 地址，点击连接
  5. 开始执行 ADB 命令！
