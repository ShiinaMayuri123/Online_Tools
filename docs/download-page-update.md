## 🚀 用户流程

### 完整流程

1. **访问下载页面**
   - 点击"下载 adb-agent.exe"按钮
   - 跳转到获取指南页面

2. **安装前置要求**
   - 下载 Android SDK Platform Tools
   - 解压到目录
   - 添加到 PATH 或复制 adb.exe

3. **获取本地代理**
   - 方式一：从源码构建（克隆、安装、打包）
   - 方式二：直接运行（需要 Node.js）

4. **运行本地代理**
   - 双击 exe 文件或运行 npm start
   - 自动打开配对页面
   - 复制 Token

5. **配对使用**
   - 返回 ADB 调试助手页面
   - 粘贴 Token 进行配对
   - 连接设备开始使用

## ❓ 常见问题

### Q: 为什么没有直接下载 exe 的链接？

A: 因为暂时没有上传 exe 文件到 GitHub Releases。我们提供了两种替代方案：
1. 从源码构建（推荐）
2. 直接运行（需要 Node.js）

### Q: 如何安装 ADB 工具？

A: 访问 Android SDK Platform Tools 官方下载页面，下载并解压，然后添加到 PATH 环境变量。

### Q: 需要安装 Node.js 吗？

A: 如果选择"从源码构建"方式，需要 Node.js 来安装依赖和打包。如果选择"直接运行"方式，也需要 Node.js 来运行程序。

### Q: 程序安全吗？

A: 是的，程序只监听 127.0.0.1（本地），不暴露到公网。使用 Token 鉴权，命令白名单等安全机制。
