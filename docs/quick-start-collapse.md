# 快速开始默认收起功能

## 📋 概述

已将"快速开始"部分设置为默认收起状态，用户点击标题即可展开查看。

## ✅ 更新内容

### 1. 新增状态

```javascript
const [showQuickStart, setShowQuickStart] = useState(false); // 默认收起
```

### 2. 折叠功能

- 点击标题栏展开/收起
- 显示折叠箭头动画
- 展开时有 fade-in 动画效果

### 3. 样式调整

- 标题栏可点击
- 箭头指示展开状态
- 内容区域条件渲染

## 🔧 技术实现

### 状态管理

```javascript
const [showQuickStart, setShowQuickStart] = useState(false);
```

### 组件结构

```jsx
<div className="bg-gradient-to-br from-slate-50 to-gray-50 rounded-lg border border-slate-200 overflow-hidden">
  {/* 标题栏（可点击） */}
  <button
    onClick={() => setShowQuickStart(!showQuickStart)}
    className="w-full px-4 py-3 flex items-center justify-between hover:bg-slate-100 transition-colors"
  >
    <div className="flex items-center gap-2">
      <Terminal size={14} className="text-emerald-500" />
      <span className="text-sm font-bold text-slate-700">快速开始</span>
    </div>
    <ChevronDown
      size={16}
      className={`text-slate-400 transition-transform duration-200 ${showQuickStart ? 'rotate-180' : ''}`}
    />
  </button>

  {/* 内容区域（条件渲染） */}
  {showQuickStart && (
    <div className="px-4 pb-4 animate-in fade-in duration-200">
      {/* WiFi 调试步骤 */}
      {/* USB 调试步骤 */}
      {/* 注意事项 */}
    </div>
  )}
</div>
```

### 样式特点

1. **标题栏**
   - 可点击的按钮
   - 悬停效果
   - 图标 + 标题 + 箭头

2. **箭头动画**
   - 使用 ChevronDown 图标
   - 展开时旋转 180 度
   - 平滑过渡动画

3. **内容区域**
   - 条件渲染
   - fade-in 动画
   - 适当的内边距

## ❓ 常见问题

### Q: 为什么默认收起？

A: 主要原因：
1. 节省页面空间
2. 快速开始主要针对新用户
3. 老用户可能不需要
4. 保持与"参考详细使用指南"一致

### Q: 如何展开？

A: 点击"快速开始"标题栏，即可展开查看详细步骤。

### Q: 可以改成默认展开吗？

A: 可以，修改代码中的初始状态：
```javascript
const [showQuickStart, setShowQuickStart] = useState(true); // 改为 true
```

### Q: 箭头方向是什么意思？

A: 
- ▼ (向下)：收起状态，点击可展开
- ▲ (向上)：展开状态，点击可收起

### Q: 动画效果是什么？

A: 使用 fade-in 动画，展开时内容渐显，提供平滑的视觉过渡。
