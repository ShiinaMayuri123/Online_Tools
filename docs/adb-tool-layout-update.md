# ADB 工具页面布局更新

## 📋 概述

已调整 ADB 调试助手页面的布局，将"快速开始"部分移到"ADB 命令参考"下方，并设置为默认收起状态。

## ✅ 更新内容

### 1. 布局顺序调整

**之前**：
1. ADB 控制台
2. ADB 命令参考（可折叠）
3. 快速开始（始终展开）

**现在**：
1. ADB 控制台
2. ADB 命令参考（可折叠）
3. 快速开始（可折叠，默认收起）

### 2. 快速开始部分改造

**之前**：
- 始终展开显示
- 使用渐变背景样式
- 占据较多空间

**现在**：
- 可折叠，点击标题展开/收起
- 使用与其他部分一致的卡片样式
- 默认收起，节省空间
- 添加折叠图标和动画

## 🎯 改动原因

1. **用户体验优化**
   - 快速开始是给新用户看的，老用户可能不需要
   - 收起状态可以节省页面空间
   - 让页面更简洁

2. **一致性**
   - 与"ADB 命令参考"保持相同的折叠样式
   - 统一的交互方式
   - 视觉效果更协调

3. **信息层次**
   - ADB 控制台是核心功能，始终显示
   - 命令参考和快速开始是辅助内容，可折叠
   - 用户可以根据需要展开查看

## 🔧 技术实现

### 状态管理

```javascript
const [showReference, setShowReference] = useState(false);  // 命令参考，默认收起
const [showQuickStart, setShowQuickStart] = useState(false); // 快速开始，默认收起
```

### 组件结构

```jsx
<div className="space-y-6">
  {/* ADB 控制台 - 始终显示 */}
  <AdbConsole />

  {/* ADB 命令参考 - 可折叠，默认收起 */}
  <div className="bg-white/80 ...">
    <button onClick={() => setShowReference(!showReference)}>
      ADB 命令参考
    </button>
    {showReference && <AdbReferencePanel />}
  </div>

  {/* 快速开始 - 可折叠，默认收起 */}
  <div className="bg-white/80 ...">
    <button onClick={() => setShowQuickStart(!showQuickStart)}>
      快速开始
    </button>
    {showQuickStart && (
      <div>
        WiFi 调试步骤
        USB 调试步骤
        注意事项
      </div>
    )}
  </div>
</div>
```

### 样式特点

1. **统一的卡片样式**
   - `bg-white/80 backdrop-blur-sm`
   - `rounded-xl sm:rounded-2xl`
   - `border border-slate-200`
   - `shadow-md`

2. **标题栏样式**
   - 可点击的按钮
   - 图标 + 标题
   - 折叠箭头动画

3. **图标区分**
   - 命令参考：蓝色书本图标
   - 快速开始：绿色终端图标

## ❓ 常见问题

### Q: 为什么要把快速开始收起来？

A: 主要原因：
1. 节省页面空间
2. 快速开始主要针对新用户
3. 老用户可能不需要
4. 保持与其他部分的一致性

### Q: 如何展开快速开始？

A: 点击"快速开始"标题栏，即可展开查看详细步骤。

### Q: 默认状态可以改成展开吗？

A: 可以，修改代码中的初始状态：
```javascript
const [showQuickStart, setShowQuickStart] = useState(true); // 改为 true
```

### Q: 快速开始的内容会丢失吗？

A: 不会，内容完整保留，只是默认收起显示。用户点击即可展开查看全部内容。
