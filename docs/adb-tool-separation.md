# ADB 调试工具分离到主页

## 📋 概述

将 ADB 调试工具从 RobotRecord 页面分离出来，作为一个独立的工具放到主页上，方便用户直接访问。

## ✅ 已完成的改动

### 1. 新增文件

| 文件 | 说明 |
|------|------|
| `src/pages/AdbTool.jsx` | 独立的 ADB 工具页面 |

### 2. 修改文件

| 文件 | 改动说明 |
|------|----------|
| `src/config/theme.jsx` | 添加 ADB 工具到 TOOLS 数组 |
| `src/App.jsx` | 添加 `/adb` 路由 |

## 🎯 工具命名

**名称**: ADB 调试助手

**理由**:
- 简洁明了，直接说明功能
- "助手"一词体现辅助调试的定位
- 与项目中其他工具命名风格一致（如"长图拼接工具"、"安全密码生成器"）

## 🔧 技术实现

### 1. AdbTool.jsx 页面结构

```jsx
const AdbTool = () => {
  const [showReference, setShowReference] = useState(false);

  return (
    <ToolLayout
      title="ADB 调试助手"
      description="局域网 Android 设备调试工具，支持 WiFi/USB 连接，实时命令执行"
    >
      <div className="space-y-6">
        {/* ADB 控制台 */}
        <AdbConsole />

        {/* ADB 命令参考面板 */}
        <div className="...">
          <button onClick={() => setShowReference(!showReference)}>
            ADB 命令参考
          </button>
          {showReference && <AdbReferencePanel />}
        </div>

        {/* 使用说明 */}
        <div className="...">
          快速开始指南
        </div>
      </div>
    </ToolLayout>
  );
};
```

### 2. 工具列表配置

```javascript
// src/config/theme.jsx
export const TOOLS = [
  {
    id: 'adb-tool',
    path: '/adb',
    title: 'ADB 调试助手',
    description: '局域网 Android 设备调试工具。支持 WiFi/USB 连接，实时命令执行，设备信息查看，日志抓取等功能。',
    icon: Terminal,

    isNew: true
```

### 3. 路由配置

```javascript
// src/App.jsx
<Routes>
  {/* 公开工具 */}
  <Route path="/adb" element={<AdbTool />} />
  {/* ... 其他路由 */}
</Routes>
```

### 特色功能

1. **可折叠的命令参考面板**
   - 点击标题展开/收起
   - 节省页面空间
   - 方便随时查阅

2. **快速开始指南**
   - 分两列显示 WiFi 和 USB 调试步骤
   - 醒目的注意事项提示
   - 新手友好的引导

3. **独立页面**
   - 不依赖 RobotRecord 页面
   - 直接从主页访问
   - 更清晰的功能定位

## 🔗 与 RobotRecord 的关系

### 保留 RobotRecord 中的 ADB 功能

RobotRecord 页面仍然保留 AdbConsole 和 AdbReferencePanel 组件，因为：
- 机器人测试记录页面可能需要 ADB 功能来调试设备
- 保持向后兼容性
- 满足特定用户的工作流程

### 功能对比

| 功能 | AdbTool 页面 | RobotRecord 页面 |
|------|--------------|------------------|
| ADB 控制台 | ✅ | ✅ |
| 命令参考面板 | ✅（可折叠） | ✅（始终显示） |
| 快速开始指南 | ✅ | ❌ |
| 机器人测试记录 | ❌ | ✅ |
| 设备详情 | ❌ | ✅ |

## 🚀 使用方法

### 访问 ADB 工具

1. 打开网站首页
2. 找到"ADB 调试助手"卡片（带"新"标签）
3. 点击进入

### 直接访问 URL

```
http://localhost:5173/#/adb
```
